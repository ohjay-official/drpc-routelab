# RouteLab for dRPC

Independent tools for people running on dRPC. Not affiliated with or endorsed by dRPC.

- **Benchmark**: timed JSON-RPC calls to dRPC public endpoints and your own routes, with a failover verdict and head lag check.
- **Cost**: monthly cost on NodeCloud against Alchemy, QuickNode and Ankr for a chosen workload.
- **Configs**: a NodeCore `nodecore.yml`, Docker and quorum commands, and a viem fallback transport.
- **Method**: how every number is produced, and the limits.

Everything runs in the browser. There is no backend and no analytics.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
